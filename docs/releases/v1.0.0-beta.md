# v1.0.0-beta

> Primeiro pre-release público do oh-my-claude-code.

## Highlights

- **Modelo de Determinismo em 3 Camadas**: L1 Commands, L2 Gates, L3 Feedback
- **Ralph Loop**: loop externo em Python para hard verify-completion
- **9 Skills Centrais**: brainstorming, planning, reviewing, debugging, research, verification, finishing, self-reflect, find-skills
- **Plan Review Multi-perspectiva**: 4 reviewers paralelos por rodada
- **Sistema de Conhecimento com Self-learning**: episodes, rules, knowledge index
- **Compatibilidade Total com Kiro CLI**: 12 hooks verificados
- **76+ Testes Automatizados**: suíte pytest cobrindo hooks, skills e ralph loop
