# v1.2.0

> Primeira release estável: framework production-ready com 13 skills, 12 commands e hooks battle-tested.

## Highlights

- **Skill Routing orientado a dados**: o hook de context enrichment agora usa trigger matching por regex a partir do frontmatter da skill, substituindo listas de keywords hardcoded
- **OpenViking Semantic Search**: query rewrite por LLM + estratégia dual de busca atinge 100% de hit rate no recall de conhecimento; gate filter + autocut para qualidade; o enforcement OV-first bloqueia busca redundante no filesystem
- **Comando `@do`**: workflow leve para tarefas pequenas, com scratchpad obrigatório e ancoragem de contexto, evitando drift em interações multi-turno
- **13 Skills**: incluímos omk-skill-creation (meta-skill), omk-youtube (extração de legendas), omk-context7-docs, omk-coding, e otimizamos todos os triggers de skill com descrições mais assertivas
- **Otimização de Lesson Recall**: indexação por perfil de cenário, exibição de top-hit do episode e injeção de LESSON no contexto
- **Melhorias no Ralph Loop**: Autonomous Problem-Solving Protocol, verificação de QA, leituras paralelas, completion review, classify_exit
- **Suporte a Worktree no comando Review**: `@review` agora respeita `.active-submodule` para revisar o código do worktree do submodule, em vez de só o projeto raiz
- **Sync de Hooks**: os hooks do framework são sincronizados automaticamente para projetos downstream via Step 1.5 do sync-omk.sh
- **Limpeza de Archive**: removidos 16K+ linhas de assets históricos da v2 já totalmente migrados

## Breaking Changes

- Todas as skills do framework agora usam o prefixo `omk-` (por exemplo, `omk-planning`, `omk-coding`)
- Os comandos foram migrados de symlinks para o diretório `.kiro/prompts/`

## Bug Fixes

- Resolvido o shadowing de symlink do sync-omk
- Correções nos testes E5/E6/E7 do validate-project
- yt-subtitle.sh agora sai cedo no glob miss
- test-split.sh corrigido para SIGPIPE com pipefail
- Bypass de dedup do context enrichment para verify de top-hit de episode
- O verify de sintaxe Markdown agora trata YAML frontmatter em SKILL.md
