# v1.1.0-beta

> Segundo beta release: otimização de contexto, execução paralela com worktree, auto-evolução do conhecimento.

## Highlights

- **Auto-Evolução do Conhecimento**: o motor de destilação compacta automaticamente os episodes em rules; tracking de severidade para learnings auto-capturados; scaffold de testes de integração
- **Ralph Loop com Worktree Paralelo**: tarefas executam em git worktrees isolados e fazem merge de volta; detecção de stall via heartbeat; fork bomb eliminado
- **Otimização de Contexto**: streamlining da saída dos hooks, destilação de episodes, prune dos resources de skill na geração de configs
- **Brainstorming → Planning Phase 0**: brainstorming foi unificado na Phase 0 do planning, em um único fluxo
- **Otimização do Fluxo de Review**: cap de rodadas de review reduzido de 5 para 3; menos reviewers a partir da Round 2; templates fill-in para os ângulos Completeness e Testability
- **Paridade com Claude Code**: testes de integração do CC promovidos para asserções baseadas em efeito; documentação dual-platform atualizada

## Bug Fixes

- A extração de comando de verify do Ralph Loop agora suporta fenced code blocks
- Correção de processos filhos órfãos depois que o ralph_loop é morto
- Eliminação de fork bomb via exclusão de precheck e guarda de recursão
- O prompt do worker passou a instruir um git commit para o merge do worktree funcionar
- Pulo de verify/test redundante no completion hook durante o ralph loop
- Correções no enforce-ralph-loop: strip do prefixo cd e ajustes na allowlist
- Sanitização de payloads de teste com paths sentinel seguros
