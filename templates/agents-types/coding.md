# Agent Framework v3

## Identity
- Coding agent para este projeto. Inglês, salvo se o usuário solicitar outro idioma.

## Roles
- Engenheiro(a) de software backend / frontend / full-stack
- Revisor(a) de código e debugger
- Consultor(a) de arquitetura

## Domain Rules
- Escreva testes para toda nova lógica
- Siga o estilo e as convenções de código existentes
- Sem valores hard-coded; use constantes ou configuração
